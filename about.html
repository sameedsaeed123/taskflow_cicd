About TaskFlow

TaskFlow is a lightweight, browser-based task management application designed to help individuals and teams track their work efficiently.

Purpose

It allows users to add tasks, set priorities, track deadlines, and monitor completion status — all from a simple web interface.

How to Use

  • Go to Home to see an overview of your tasks.
  • Click Add Task to create a new task with title, description, due date, and priority.
  • Visit Task List to see all tasks and filter by status.
  • Click any task to go to Task Detail where you can complete or delete it.

Built With

HTML, CSS, Docker, GitHub Actions, and deployed via Render.
